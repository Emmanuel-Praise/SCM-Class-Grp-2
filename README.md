# 👜 BagHaus — Bags & Accessories Storefront

A lightweight, dependency-free storefront built with **vanilla HTML, CSS and JavaScript**.
Created as a Software Configuration Management (SCM) course project — Group 2.

---

## ✨ Features

- Responsive product grid with category filters (Bags, Accessories, Footwear)
- Slide-out shopping cart with quantity controls and live subtotal
- Cart badge, toast notifications and empty-cart state
- SVG icon fallbacks if product images are missing
- Fully keyboard accessible, no frameworks or build step

---

## 🛠 Tech Stack

HTML5 · CSS3 (custom properties, Grid, Flexbox) · Vanilla JavaScript (ES6+) · Inline SVG
